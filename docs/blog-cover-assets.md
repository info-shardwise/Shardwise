# Blog cover assets

Generated on 12 October 2026 using the built-in imagegen tool in generation mode. Covers are optimized WebP files at 1200 × 800 pixels in `public/images/blog/covers/`.

Each prompt used this opening: “Create a wide 3:2 editorial blog cover illustration for a software agency.”

Topic-specific prompt sections:

- Website maintenance: “Website maintenance: a polished browser dashboard with checklist marks, shield and small tools, blue and lavender with warm peach accents.”
- Shopify maintenance: “Ecommerce store maintenance: a stylish miniature storefront, product boxes and a shopping bag, emerald and cream palette, editorial 3D illustration.”
- WordPress staging: “Website staging and release: two distinct browser panels connected by a deployment arrow, a preview checklist and isolated test environment, violet and pale blue palette.”
- WooCommerce checkout: “Checkout testing: a cart, payment card and receipt connected by checkmarks, coral and deep teal palette, polished editorial 3D illustration.”

Each prompt ended with: “Crisp premium composition, soft studio lighting, large central objects, plenty of breathing room safe for 16:9 crops. No text, no letters, no brand logos, no watermark. Save the image for website use.”

The two earlier articles retain their separate existing stock images. All articles explicitly declare `image` and `imageAlt` in front matter. These fields supply blog thumbnails, social previews and BlogPosting image metadata. Originals remain in the local Codex generated-images folder.
